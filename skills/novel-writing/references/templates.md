# 模板

照抄下面的骨架建立文件，删掉说明文字后填写实际内容。

## 交付格式

默认（连写关闭）——`ask_user_question` 内容：

```text
第 NN 章《<标题>》已完成
- 文件：<书名>/章节/第NN章-<标题>.md（约 N 字）
- 摘要：1) … 2) … 3) …
- 伏笔：新埋 F00X …；回收 F00Y …
- 状态更新：02-设定圣经.md 的人物/名词；03-进度日志.md 的进度
- 下一章计划：<一句话>
- 开关：关闭
请选择：确认，继续下一章 / 本章需要修改 / 调整设定或大纲
```

连写开启时——每章只回一行，满 N 章后再汇总确认：

```text
第NN章《标题》已完成｜<书名>/章节/第NN章-<标题>.md｜<一句摘要>｜连写剩余 N 章
```

## 长篇卷表与卷纲

01 中每卷一行；建卷才补充分段章纲。旧正文直接记原路径。

| 卷号与卷名 | 预计全书章号／字数 | 卷初局面 → 卷终变化 | 跨卷伏笔 ID | 卷纲路径 | 实际章数／字数 |
| --- | --- | --- | --- | --- | --- |
| V001 | C000001–C000100／约 25 万 | | | 分卷/V001/卷纲.md | |

```markdown
# V001 <卷名>
- 主线与本卷必须回答的问题：
- 人物弧光与不可提前获知的信息：
- 起点（接上一卷哪条事实／结束动作）：
- 阶段转折、高潮与代价：
- 场景依赖：哪几章可独立起草／哪些必须等前章定稿：
- 分段章纲路径与全书章号范围：
- 待回收表／卷末交接路径：
```

## 长篇章卡

```markdown
# V001 / C000001 <标题>
- 正文路径、实际字数（全书统一计数口径，例：除标题、空白和标点的正文字符）：
- 时间、地点、视角、场景先后：
- 起因 → 抉择 → 后果（3–5 条摘要）：
- 状态变化（实体 ID，含谁亲历、谁误解、谁仍不知情）：
- 新埋／兑现／延期的伏笔 ID、证据段、回收窗口：
- 结尾动作／对白与下一章必须承接的细节：
- 需更新的分档、索引及路径：
```

## 场景委派单（可写进 offer 的任务说明）

```text
书根／脚本绝对路径：

输入：卷纲、章纲、前章卡、人物与伏笔分档的路径：
场景从哪里开始，到哪一个动作或决定结束：
谁知道什么、本场景可以改变什么、禁止提前揭示什么：
字数与文风重点：
交付：take 后只写本人 token 目录。submit 场景稿／核查报告，附事实增量与待决问题。
```

## 卷末交接

```markdown
# V001 → V002
- 已交付章号区间／实际字数／全书累计：
- 卷初承诺、已兑现的变化及对应章卡：
- 主线最后一个不可逆事件及证据章：
- 存活人物的目标、关系、持有物、所在位置与知情差：
- 仍然开放的伏笔 ID → 下卷窗口与负责支线：
- 时间线锚点、地理限制、文风的已批准调整：
- 下一卷第一幕的起点与禁写事项：
```
