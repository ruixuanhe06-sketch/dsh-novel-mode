# 模板

照抄下面的骨架建立文件，删掉说明文字后填写实际内容。

## 00-创作说明.md

```markdown
# 创作说明：<书名>

## 用户原始输入（照抄，不要改写）
- 灵感：
- 内容与剧情要求：

## 整理后的创作目标
- 体裁／题材：

- 叙事视角与人称：
- 基调与风格：
- 尺度与禁忌：
- 结局倾向（开放／明确）：
- 交付方式偏好：逐章确认（默认）／连写 N 章

## 材料清单
- 用户提供的大纲文件：<路径，若有>
- 用户提供的参考作品（只提炼文风）：<路径，若有>
- 其他补充说明：
```

## 章节正文模板：章节/第NN章-<标题>.md

```markdown

```

## 交付格式

默认（连写关闭）——`ask_user_question` 内容：

```text
第 NN 章《<标题>》已完成
- 文件：<书名>/章节/第NN章-<标题>.md（约 N 字）
- 摘要：1) … 2) … 3) …
- 伏笔：新埋 F00X …；回收 F00Y …
- 状态更新：02-设定圣经.md 的人物/名词；03-进度日志.md 的进度
- 下一章计划：<一句话>
- 开关：关闭
请选择：确认，继续下一章 / 本章需要修改 / 调整设定或大纲
```

连写开启时——每章只回一行，满 N 章后再汇总确认：

```text
第NN章《标题》已完成｜<书名>/章节/第NN章-<标题>.md｜<一句摘要>｜连写剩余 N 章
```
