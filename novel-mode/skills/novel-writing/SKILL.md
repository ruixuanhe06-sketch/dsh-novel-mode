# 小说创作工作手册

本模式以「章」为最小创作单位。**默认一章一次交付，用户确认后才写下一章**；用户明确开启「连写开关」时按开关章数连续写作。

## 一、作品目录

每部小说一个目录（默认当前工作目录下以书名命名）：

```
<书名>/
  00-创作说明.md      用户的灵感、题材、要求（原文 + 整理），以及交付方式偏好
  01-大纲.md          章节清单：标题 / 目标事件 / 预计字数 / 伏笔安排
  02-设定圣经.md      ★跨章上下文：人物、世界观、时间线、伏笔登记表、名词表
  03-进度日志.md      顶部「写作开关」+ 进度、剧情位置、未回收伏笔、下一章计划
  04-文风设定.md      ★文风档案：视角、句长节奏、用词、对白比例、标点排版、钩子手法、忌用项
  参考资料/           用户提供的参考作品（只作抽样阅读，原文不进入产出）
  章节/第NN章-<标题>.md
```

模板见 `references/templates.md`（相对本技能目录；用文件读取工具打开后照抄）。
用户提供了大纲文件时，先读原文再转写进 `01-大纲.md`，不要另写一套相互矛盾的设定。

## 二、设定圣经（02）——跨章事实的唯一权威

任何一章开写前都必须重新读取 `02-设定圣经.md`、`03-进度日志.md` 与 `04-文风设定.md`。

| 区块 | 记什么 | 什么时候更新 |
| --- | --- | --- |
| 人物 | 身份、性格（含缺点）、动机、说话方式、外貌特征、当前状态与所在位置、人物关系 | 人物首次登场、状态或关系变化时 |
| 世界观 | 规则、势力、地理、时代、力量体系及其代价 | 新设定出现时 |
| 时间线 | 事件发生的先后与间隔、当前故事时间点 | 每章结束时 |
| 伏笔登记表 | 编号、埋设章、内容、计划回收章、状态（未回收/已回收/已放弃） | 每埋一个、每回收一个 |
| 名词表 | 专有名词、称谓、道具、招式、地名的统一写法 | 新名词首次出现时 |
| 禁忌 | 与既定设定冲突的写法、不能出现的内容 | 一旦发现立刻记录 |

规矩：
- 伏笔必须先登记再埋，编号连续（F001、F002…），回收后改状态并写明回收章。
- 不改人物性格去迎合剧情；剧情要为人物的性格与动机让路。
- 任何与既有条目冲突的新内容，先改 02 再落笔，并在交付时明确告诉用户改了哪一条。

## 三、文风档案（04）——参考作品只提炼文风

用户把**其它已经完成的小说**作为材料给你时，本作只吸收它的**文风**，绝不吸收它的内容。

提炼流程：
1. **抽样阅读**，不整本读入上下文：开篇、中段、对白密集段、高潮段、结尾各取 1–3 段（每段 300–800 字）；大文件用 offset/limit 或按字节分段抽样。材料放在 `参考资料/`，只读不抄。
2. **按维度提炼**：叙述视角与人称/时态；平均句长与长短句分布；段落长度与断行；用词层级（书面/口语/方言）与高频连接方式；比喻与意象偏好；对白占比、提示语位置与说话方式标记；动作/心理/环境描写比例；标点与排版习惯（省略号、破折号、引号、空行）；场景切换、时间跳跃、章节收束与钩子的做法；情绪温度与幽默感；要规避的套话清单。
3. **写成可执行规则**，不要只写形容词。例：「短句为主，平均 15–20 字；每段不超过 4 行；对白占四成；心理用行为外化；每章最后一节留半句未完成的对白」。
4. **单列「不得模仿项」**：原作的人物名、地名、组织、专有名词、独有设定与具体桥段——本作只能借文风，不能借内容。
5. **写入 `04-文风设定.md`**（注明参考来源文件名与提炼日期），交用户确认后即成为本作文风；此后每章都按它写，交付前自查是否走样。
6. 用户没给参考作品时，按题材与要求定一份稳妥的默认文风写进 04，并标注「默认文风」。
7. 任何产出文件都不得抄录参考作品原文；引用只用于抽样分析、不落盘。

## 四、连写开关（逐章暂停的唯一例外）

开关状态存放在 `03-进度日志.md` 顶部的「写作开关」区块，**每章开写前必读**，不凭记忆：

```markdown
## 写作开关
- 连写模式：关闭
- 剩余可连写章数：0
- 开启来源：—
- 到期行为：剩余为 0 时自动关闭并恢复逐章暂停
```

- **开启**：只有用户明确说出连写与章数（「开启连写 5 章」「后面 10 章不用问我」）才开启，并把状态写进 03。「你继续写吧」只等于确认一章，不是连写；不得自行开启或延长。
- **连写期间**：同一轮内逐章写作；每章仍逐章保存、逐章更新 02/03/04、逐章自查；不允许先写 N 章草稿再回头补设定。每章写完只回一行 `第NN章《标题》已完成｜<文件路径>｜<一句摘要>｜连写剩余 N 章`，不调用 `ask_user_question`。
- **计数与收尾**：每章完成后剩余章数减 1，减到 0 立即把连写模式改回关闭；写满后停下，给出整批汇总（每章一行 + 伏笔变化 + 下一章计划）并用 `ask_user_question` 请用户确认。
- **上限**：单次最多 10 章；要更多就分批，每批结束必须暂停确认。
- **必须中止连写并提问**：剧情分叉需要用户决定、设定冲突、素材用法不确定、用户此前要求互相矛盾时——不得自行决定后继续。
- **取消**：「停下并恢复逐章确认」→ 立刻把开关改回关闭。
- **状态显式**：每次交付都带「开关：关闭／开启（剩余 N 章）」。

## 五、单章循环（每次写作都照此执行）

1. **读**：读 `02-设定圣经.md`、`03-进度日志.md`（含顶部写作开关）、`04-文风设定.md`、`01-大纲.md` 中本章条目。禁止凭记忆写作。
2. **报**：用不超过 3 行说明本章目标、涉及人物与伏笔、文风要点。
3. **写**：一章一个文件，默认 2000–4000 字（用户有要求以用户为准）。顺序推进，不跳章、不并章、不预告下一章正文。按 04 的文风落笔，结尾留钩子。
4. **存**：写入 `章节/第NN章-<标题>.md`（章号补零两位）。
5. **更**：更新 02（伏笔、人物状态、新名词）、03（进度、下一章计划；连写时剩余章数 −1）、04（本章如有文风手法调整）。
6. **交付**：连写关闭 → 调用 `ask_user_question`（id `chapter_review`）：文件路径、3–5 条摘要、埋下/回收的伏笔、下一章计划、开关状态；选项 `确认，继续下一章` / `本章需要修改` / `调整设定或大纲`。连写开启 → 只回一行并继续下一章。
7. **改或续**：得到修改意见就先改本章与受影响的 02/03/04 并重新提交；得到确认（或连写未满）才写下一章。

硬性禁止：连写关闭时用户未确认就写下一章；把一轮里连写当成默认行为；用解释、预告或「稍后确认」替代暂停；把参考作品的原文或内容搬进本作。

## 六、质量检查清单（每次交付前自查）

- 视角与人称与 00/01 一致，通篇没有视角漂移。
- 文风与 04 的规则一致：句长节奏、段落长度、对白比例、标点习惯没有走样。
- 人物言行符合 02 中记录的性格与说话方式，不同角色的语言有区分度。
- 本章有明确的推进：至少完成一个情节点，或显著改变人物处境。
- 伏笔按登记表埋设/回收；本章新埋的已登记。
- 没有出现参考作品中的人物名、专有名词与具体桥段。
- 删掉套话式的情绪总结与空泛描写，用具体动作、细节、对白替代。
- 场景转换、时间跳跃清晰；字数符合要求；结尾钩子自然。

## 七、常见情况

- **上下文被压缩或隔天续写**：重读 02、03（含开关）与 04 再动笔，不要相信记忆。
- **用户要求改设定/改大纲**：先改 01/02/03（涉及文风时连 04 一起改），再继续写作，并在交付时说明改动。
- **用户一次给出多章要求**：默认仍逐章确认；用户明确开启连写时才连写，且逐章保存、逐章更新，写满必须停。
- **需要考据**：现实细节（地名、年代、器物、职业流程、风俗）用 `web_search` 查证、必要时 `web_fetch` 读原文；查到的关键事实写进 02 的对应条目（专有名词写进名词表），不得引入与 02 冲突的内容。
- **写完后**：整部完结时汇总 `03-进度日志.md`，检查伏笔是否全部回收或明确标记为开放，并把 04 的最终文风规则固化下来。
